For every element with odd index, it will store the difference of current and previous element.

Input: a[8]= {2,3,5,6,12,9,1,0}, size=8 
 
Output = 5, 1, 11, 1, 21, 3, 1, 1 
Reason =  
2+3 = 5 
|2-3| = 1 
5+6 = 11 
|5-6| = 1 
And so on.

    return 0;
}

	        if(a[i]>a[i-1]){

	}

	}
}
